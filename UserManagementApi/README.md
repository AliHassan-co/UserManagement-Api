# User Management API (ASP.NET Core)

ASP.NET Core Web API with CRUD operations (`GET`, `POST`, `PUT`, `DELETE`), validation, and custom middleware.

## Copilot Debugging Notes
- Used Microsoft Copilot to scaffold endpoints, DTOs, and middleware.
- Used Copilot during debugging to handle invalid IDs (`400`), missing users (`404`), duplicate emails (`409`), and thread-safe list access.
